# ربات تقویم روزانه تلگرام

این نسخه برای اجرای روزانه در GitHub Actions آماده شده است؛ لپ‌تاپ لازم نیست روشن باشد.

## فایل‌ها
- `bot.py`: کد ربات
- `requirements.txt`: وابستگی‌ها
- `.github/workflows/daily-calendar.yml`: اجرای روزانه ساعت ۸ صبح به وقت تهران

## راه‌اندازی
1. یک مخزن (repository) در GitHub بسازید. برای اجرای Actions بدون هزینه، مخزن عمومی ساده‌ترین گزینه است؛ توجه کنید که کد عمومی دیده می‌شود.
2. این فایل‌ها را در مخزن قرار دهید و روی شاخه پیش‌فرض (معمولاً `main`) ذخیره کنید.
3. از مسیر Settings → Secrets and variables → Actions → New repository secret دو Secret بسازید:
   - `BOT_TOKEN`: توکن ربات از BotFather
   - `CHANNEL_ID`: شناسه عددی کانال (مثلاً `-100...`) یا `@channelusername`
4. مطمئن شوید ربات در کانال ادمین است و اجازه ارسال پیام دارد.
5. در Actions، گردش‌کار `Daily Persian Calendar` را باز کنید و با `Run workflow` یک بار دستی آزمایش کنید.

پس از موفقیت آزمایش، GitHub زمان‌بندی اجرای روزانه را انجام می‌دهد. زمان‌بندی ممکن است به‌دلیل بار سرویس کمی دیرتر اجرا شود و تضمین دقیقه‌ای ندارد.

## نکته مهم
این روش در هر بار اجرا، یک پیام می‌فرستد و تمام می‌شود؛ ربات به‌صورت دائمی روشن نمی‌ماند. بنابراین دستورهای `/today` و `/test` فقط وقتی پاسخ می‌دهند که نسخه دائمی/پولینگ ربات جداگانه‌ای در حال اجرا باشد.

دسترسی مستقیم GitHub Actions به `api.telegram.org` باید در اولین اجرای دستی آزمایش شود. اگر اتصال از runner برقرار نشود، این روش بدون واسطه شبکه کار نخواهد کرد.

برای حفظ امنیت، توکن را داخل کد یا فایل‌ها ننویسید و در مخزن عمومی قرار ندهید؛ فقط از GitHub Secrets استفاده کنید.
